# Forces et faiblesses des 6 médias

Les tableaux complets, pour arbitrer un plan média.

---

## 1. La TV — SEE, THINK, DO, CARE

*En déclin depuis plusieurs années. Tendances : TV connectée à internet, streaming et VOD,
multi-screen. Possibilités : TV classique, replay, streaming, YouTube. Parrainage TV : « Ce
programme vous est présenté par… »*

| Forces | Faiblesses |
|---|---|
| Ciblage **plus fin** en TV digitale | La **passivité** des utilisateurs, due à la multiplication de l'utilisation de devices en simultané |
| Grande **diversité de formats** — encore plus grande avec la TV digitale | Pour une répétitivité optimale, le **coût de création et de diffusion** sont énormes |
| Média permettant d'atteindre **tous les objectifs** de communication | **Planification assez long terme** |
| Média **puissant** grâce à la combinaison du son et de l'image = impact | |
| **Large couverture** | |
| Efficace pour le **long terme** | |
| Engagement plus important avec la TV digitale | |

**Bonnes pratiques :** plus de 3 visionnages · répétition et long terme · **la création est la
clé** · choisir un bon créneau.

---

## 2. Le cinéma — SEE, THINK, CARE (DO)

*Moins d'1 % du total des recettes des grands médias.*

| Forces | Faiblesses |
|---|---|
| Une **grande force de communication** : la dimension de l'image, la qualité du son, la disponibilité du public — **l'attention** | La distribution des contacts est **lente** = couverture |
| Grâce à sa force de communication, le cinéma est le média avec le **taux de mémorisation publicitaire le plus élevé** | La **répétition est faible** : même les fans de cinéma n'y vont pas tous les jours |
| Bonne **sélectivité géographique** : plan média salle par salle | **Saisonnalité** : l'audience est faible en été |
| | Le **coût** de la publicité est élevé par rapport à l'audience touchée = couverture |

**Bonnes pratiques :** expérience immersive · formats longs.

---

## 3. La radio — SEE, THINK, DO, CARE

*70 % des Belges écoutent tous les jours. Tendance : les podcasts.*

| Forces | Faiblesses |
|---|---|
| Média permettant de développer des **actions ponctuelles et locales** : les stations locales permettent une couverture géographique ciblée selon les zones de chalandise des magasins, et une diffusion au moment approprié | **Possibilités créatives limitées** |
| La radio permet de faire de la **répétition** avec une **distribution rapide** des contacts | Média **passif** : les utilisateurs écoutent en faisant autre chose en même temps |
| Il y a **peu de contraintes** pour la production des messages, et les frais techniques sont peu élevés | Média qui demande **beaucoup de répétitions**, car la mémorisation des spots est faible |
| La radio est écoutée **tous les jours et tout au long de la journée** | |
| La radio est un **média de confiance** | |

**Bonnes pratiques :** créativité · ancrage local · jingles · voix connue · répétition.

---

## 4. L'OOH (Out Of Home) — SEE, THINK, DO (CARE)

*Formats : mobilier urbain, grand format, transport public, digital OOH, DOOH programmatique,
fake out of home (en ligne, ex. : le sac géant).*

| Forces | Faiblesses |
|---|---|
| **Grande visibilité**, très bonne couverture | **Public cible en mouvement** lors du contact avec ce moyen publicitaire (QR code) |
| Un **grand nombre de personnes** peut être visé | **Faible mémorisation** si peu de répétition, ou trop de textes, ou pas assez de visuel sur l'affiche |
| Moyen publicitaire **continu** : diffusion du message non-stop | Moyen publicitaire parfois considéré comme **manipulateur** |
| **Variété de formats** et de touchpoints | **Environnement et durabilité** : le secteur évolue et s'adapte (matériaux, encre) |
| Les affiches ne sont **pas considérées comme dérangeantes** par les consommateurs | |
| **Impact rapide** | |

**Bonnes pratiques :** keep it simple · logo visible · lisible · couleurs contrastées ·
respecter le sens de lecture · originalité.

---

## 5. La presse — SEE, THINK, DO, CARE

*En baisse. Types : quotidienne, magazine, professionnelle, gratuite, digitale.
Formats : classique (1 ou ½ page), publireportage, encart, coupon détachable.*

| Forces | Faiblesses |
|---|---|
| **Sélectivité géographique et démographique** | **Couverture limitée** |
| **Crédibilité** de l'information et publicité informative | **Risque de saturation publicitaire** sur certains supports |
| **Longue durée de vie** du message et bonne circulation des messages | |
| Lecture du message **à plusieurs endroits** | |
| Les publicités dans la presse sont considérées par les consommateurs comme le **moyen publicitaire le moins dérangeant de tous** | |

**Bonnes pratiques :** émotions · action · intérêt · actualité · créativité.

---

## 6. Le display — SEE, THINK, DO, CARE

*Type d'annonce publicitaire diffusée sur un site tiers. RTB (enchère en temps réel),
remarketing = retargeting. Formats : bannières, pavés, skyscrapers, interstitiels, overlays,
pop-ups. Types : images statiques, publicité rich media.*

| Forces | Faiblesses |
|---|---|
| **Couverture et portée** → permet de développer la notoriété d'une marque | Les **ad blockers** : des internautes choisissent de ne pas voir de pub |
| **Très bon ciblage** de l'audience | **Indifférence** face au nombre de bannières publicitaires vues chaque jour |
| Publicité **adaptable à chaque groupe cible** | Les clics sur les bannières peuvent être de **mauvaise qualité** → impact négatif sur la facturation |
| Possibilité de **réaction et d'action directe** de la part de l'audience → CTA | |
| **Faible coût** | |
| **Ajustements** de la publicité **en cours de campagne** possibles | |

**Bonnes pratiques :** bon format · réduire le poids du fichier · soigner le contenu ·
choisir la bonne position.

---

## Le tableau d'arbitrage rapide

| Si vous cherchez… | Le média à privilégier |
|---|---|
| La **mémorisation** maximale | Cinéma |
| La **couverture** large et rapide | TV, OOH |
| L'**ancrage local** | Radio locale, OOH, presse régionale |
| Un **budget serré** | Radio, display |
| La **crédibilité** de l'information | Presse |
| Le **ciblage précis** | Display, TV digitale |
| La **réaction immédiate** (CTA) | Display |
| Un **ajustement en cours de route** | Display |
| Un message **long et détaillé** | Presse, cinéma |
| Un message **simple et répété** | Radio, OOH |
